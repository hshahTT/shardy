# Compile Commands Setup

This directory contains tools to fix `compile_commands.json` generated by `hedron_compile_commands`.

## Problem

`hedron_compile_commands` doesn't always capture all necessary include paths, especially:
- Workspace root paths needed for `#include "shardy/..."` style includes
- Bazel output paths for generated headers (TableGen-generated files)

This causes IDEs to fail to resolve symbols like `AxesPerFactor` and `OpShardingRuleAttr`.

## Solution

Use the automated wrapper script that refreshes and fixes `compile_commands.json` in one step.

## Usage

### Option 1: Use the wrapper script (Recommended)

```bash
./refresh_compile_commands.sh
```

This script:
1. Runs `bazel run @hedron_compile_commands//:refresh_all`
2. Automatically fixes missing include paths using `tools/fix_compile_commands.py`

### Option 2: Manual steps

If you prefer to run steps separately:

```bash
# Step 1: Refresh compile_commands.json
bazel run @hedron_compile_commands//:refresh_all

# Step 2: Fix include paths
python3 tools/fix_compile_commands.py
```

## What the fix script does

The `fix_compile_commands.py` script:
1. Adds workspace root (`-I/localdev/hshah/shardy`) to all compile commands
2. Adds bazel-out paths for SDY-related files to access generated headers

## Files

- `fix_compile_commands.py`: Python script that fixes include paths in `compile_commands.json`
- `../refresh_compile_commands.sh`: Wrapper script that runs refresh + fix
